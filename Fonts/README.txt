XIVPlates' fonts, each under the SIL Open Font License:
- XIV.ttf: M PLUS 1p Medium by The M+ Project Authors (OFL.txt). The default.
- Michroma.ttf: Michroma by Vernon Adams (Michroma-OFL.txt), wide like FFXIV's gauge numbers.
- SourceSans3.ttf: Source Sans 3 by Adobe (SourceSans3-OFL.txt).

To use a different font, replace XIV.ttf with your own file under the same name, then restart
the game (a /reload won't pick up a changed font file).
